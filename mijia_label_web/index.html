1. 扫码连接 / 打开页面

本页由你的电脑本机服务提供。手机需要和电脑连在同一个 Wi-Fi / 局域网中，扫描二维码即可打开同一个标签设计页面。

手机扫码打开 正在获取地址…

如果手机无法打开，请确认两台设备在同一网络，且 Windows 防火墙允许 Python 访问局域网端口。

2. 设计标签

图片会自动缩放到 96 点宽，并按阈值转成黑白。

组合标签会从上到下依次排列：文字、二维码、条形码；空白项会自动跳过。

3. 标签预览

输入内容后会自动生成 96 点宽黑白预览。

4. 批量打印 CSV / Excel

支持上传 .csv、.tsv、.xlsx、.xlsm，也可以直接粘贴表格。第一行必须是列名；模板中使用 {列名} 读取每行数据。
